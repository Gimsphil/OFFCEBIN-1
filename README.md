OFFICE BIN — 하나의 앱으로 모든 업무를 해결하는 스마트 오피스 & 실측·적산 스튜디오
배포 형태: 100% 완전 독립형 포터블 오피스 (경로 비의존적 자립 구조)
설치 위치: 사용자가 원하는 모든 드라이브 및 폴더 (C:\, D:\, 외장 SSD, USB 드라이브 등)
애플리케이션 명칭: OFFICE BIN
버전: v1.1.0 (엔진 통합 및 28% 용량 최적화 완료, Core Engine v0.12.5)
라이선스: Apache-2.0

OFFICE BIN은 특정 폴더나 고정 경로에 종속되지 않는 완전 독립 포터블(Portable) 구조로 설계되었습니다. 사용자가 원하는 드라이브와 폴더 어디에 복사하거나 이동하더라도, 자체 상대 경로(%~dp0 / __dirname)를 통해 워드, 엑셀, PPT, 한글(HWP), PDF, 마크다운, 마인드맵, 그리고 전문 CAD 도면 실측·적산(Takeoff)까지 하나의 통합 앱 안에서 모든 업무를 막힘없이 완벽하게 해결합니다.

🚀 빠른 실행 방법 (설치 폴더 내에서 즉시 실행)
1. 네이티브 데스크톱 앱 실행 (가장 권장)
OFFICE BIN.exe (또는 runtime/OFFICE BIN.exe) 더블 클릭
또는 폴더 내의 run.bat 실행
백그라운드 무음 실행: OFFICE BIN.vbs
2. 로컬 웹 스튜디오 브라우저 모드
web.bat (또는 OFFICE BIN Web.bat) 실행
기본 브라우저에서 http://localhost:5252에 접속하여 데스크톱 앱과 동일한 모든 문서 편집 및 도면 실측/적산 작업 가능
3. 터미널 CLI 명령어 실행
설치 폴더 내의 office-bin.cmd를 사용하여 커맨드라인에서 문서를 즉시 변환하고 텍스트를 추출할 수 있습니다:

# 버전 및 상태 확인
.\office-bin.cmd --version

# 전체 도움말 확인
.\office-bin.cmd --help

# 문서 포맷 상호 변환 (예: PDF -> DOCX)
.\office-bin.cmd convert "설계문서.pdf" --to docx

# 아래아한글(HWP) 본문 텍스트 즉시 추출
.\office-bin.cmd hwp read "공문서.hwp" --full

[도면 열기] ➔ [스케일 2점 맞춤 (임의 거리 입력)] ➔ [CAD PL선 / 면적 / 수량 산출] ➔ [엑셀시트 자동 내보내기]
1. 기준 스케일(축척) 2점 사용자 직접 입력 (Calibration) & 첫 번째 점 후 휠 정밀 줌
도면 상의 알고 있는 기준 치수의 첫 번째 점과 두 번째 점을 마우스로 클릭합니다.
첫 번째 점 클릭 후 실시간 휠 줌(최대 500% 초정밀 확대): 첫 번째 기준점을 클릭한 상태에서 마우스 휠을 돌리면 첫 번째 점이 도면 좌표에 완벽 고정된 채 화면이 500%까지 확대/축소되어, 두 번째 점을 정확한 치수선 모서리에 픽셀 단위로 정밀하게 찍을 수 있습니다.
Shift / Ctrl 키 누른 상태 휠 줌: 직교(Ortho) 수평/수직 구속을 위해 Shift 키를 누르고 있거나 Ctrl 키를 누른 상태에서도 마우스 휠 확대/축소가 매끄럽게 동작합니다.
휠 버튼(Middle Click) 화면 이동(Pan): 마우스 휠 버튼을 누르고 드래그하면 진행 중인 기준점이나 선분을 취소하지 않고 도면의 원하는 구역으로 자유롭게 팬 이동할 수 있습니다.
CAD OSNAP 및 Shift 직교 모드 연동: 스케일 기준점 측정 시에도 끝점/중간점 자석 스냅과 Shift 수평/수직 직교 구속이 완벽하게 지원됩니다.
화면 중앙에 심플하고 가독성 높은 **[기준 스케일 거리 입력 모달]**이 자동 팝업되어 두 점 사이의 픽셀 거리(px)를 표시합니다. 불필요한 빠른 프리셋 버튼들을 전면 제거하여 순수하게 실제 거리와 단위 입력에 집중할 수 있도록 UI를 간소화했습니다.
사용자는 100 mm, 500 mm, 1,200 mm, 3.5 m 등 원하는 실제 거리와 단위(mm, cm, m)를 자유롭게 직접 입력할 수 있습니다.
스케일 입력 완료/취소 시 커서 자동 최초 복귀 (Default Cursor Reset): [스케일 적용] (Enter) 또는 [취소] (ESC) 시, 스케일 캘리브레이션 명령어가 즉시 완전히 종료되고 크로스헤어(십자선) 커서가 최초의 기본 커서(default)로 깨끗하게 복귀하여 다음 작업을 즉시 대기합니다.
스케일 리셋 버튼을 통해 언제든 기본값(1 px = 1.00 mm)으로 초기화할 수 있습니다.

4. CAD 2-클릭(Click-Move-Click) 정밀 측정 & 실시간 동적 커서
AutoCAD 표준 2-클릭(Click 1 ➔ Move ➔ Click 2) 방식 도입: 마우스 버튼을 누르고 있는 불편한 드래그 방식을 전면 개편하여, 1번 클릭으로 시작점을 찍고, 마우스 버튼에서 손을 뗀 상태로 자유롭게 이동하여 2번 클릭으로 끝점을 찍는 AutoCAD 표준 2-클릭 상호작용을 지원합니다. (기존 누른 채 드래그하는 방식도 완벽 호환)
축척 일치 100% 정밀도 & 직관적 치수 표기 (formatCadDistance): 시작점과 끝점 픽셀 거리가 화면 이동(Pan)에 의해 왜곡되지 않고 도면 좌표계에 완벽 일치합니다. 스케일 맞추기(Calibration)에서 1,000 mm를 입력한 후 측정하면 L: 1,000 mm (1.00 m)와 같이 도면의 실제 mm 치수와 m 환산값이 함께 명확히 출력되어 수치 오인이 완전히 방지됩니다.
PDF 페이지별 완전 독립 격리 (pdfAnnotationsByPage): 다중 페이지 PDF 문서에서 1페이지에 작성한 측정선과 주석이 2페이지, 3페이지로 따라가지 않으며, 각 페이지별로 주석과 측량 객체가 완전히 격리 보존됩니다. 적산 집계표 및 엑셀 시트 내보내기 시 페이지 번호(P.1, P.2)와 함께 통합 집계됩니다.
PDF 및 도면 벡터 초고해상도 렌더링: PDF 확대 시 CSS 확대 왜곡 대신 뷰포트 스테이지 규격에 맞추어 Chromium 네이티브 PDFium 벡터 렌더러가 화면 해상도에 맞게 1:1로 직접 렌더링하므로, 500%까지 확대해도 글자와 선이 깨지지 않고 면도날처럼 선명합니다.
실시간 러버밴드 가이드 및 거리 뱃지 동시 출력: 첫 번째 점을 찍은 후 마우스를 움직이는 동안 점선 가이드라인과 함께 실시간 실측 거리 뱃지(L: 1,000 mm (1.00 m))가 마우스 커서를 따라다니며 미리보기를 제공합니다.
CAD 동적 커서 상태 전환 및 바탕화면 클릭 자동 종료 (Auto-Reset):
도구 활성화 / 대기 상태: 정밀 CAD 십자선(crosshair) 커서 표시.
작도 진행 중: 십자선 커서와 함께 러버밴드 및 실시간 측정값 표시.
작도 완료 / 대기 복귀: 측정 후 빈 바탕화면을 마우스로 클릭하면 활성 도구가 자동 마침되고, 선택된 객체와 러버밴드가 즉시 정리되며 커서가 기본 화살표(default)로 자동 복귀합니다.
키보드 명령어 제어 & ESC 취소:
Space / Enter: 현재 진행 중인 폴리라인, 다각형, 직선 작도 즉시 마침/완료.
ESC: 진행 중인 제도/측정 즉시 취소, 도구 해제, 커서 기본 화살표 복원, 선택 객체 해제.
바탕화면 클릭 클린 종료: 작도 완료 후 빈 캔버스 바탕화면을 클릭하면 선택된 객체와 임시 형상이 즉시 해제되어 작업 흔적 없이 깔끔하게 완료 상태로 정리됩니다.

초고해상도(High-DPI) 네이티브 벡터 선명 줌 렌더링 (흐릿함/픽셀 깨짐 100% 근절):
PDF 도면 확대 시 기존의 저해상도(1000px) 캔버스를 CSS transform: scale()로 확대하여 측정 수치 글자와 선이 흐릿하고 뭉개지던(Bilinear Blur) 현상을 근본적으로 해결.
뷰포트 확대율(pdfScale) 및 디스플레이 DPI(devicePixelRatio)에 맞추어 캔버스 내부 버퍼 해상도를 Math.round(baseW * scale * dpr)로 동적 할당하고, CSS transform의 scale()을 배제하여 1:1 물리 화소 매핑 달성.
ctx.setTransform(scale * dpr, 0, 0, scale * dpr, 0, 0) 변환 행렬을 적용하여 100%~500% 초정밀 확대 상태에서도 치수 숫자, 알약 뱃지 라벨, 측정선, 화살표, 정점 도트가 하드웨어 네이티브 서브픽셀 안티앨리어싱으로 AutoCAD 및 Bluebeam Revu 수준의 칼날 같은 벡터 선명도로 렌더링됨.
줌 불변(Screen-Invariant) CAD 측정 도구: PDF 도면을 100%~500%까지 초정밀 확대하더라도 측정선 두께(2px), 정점 도트, 그립 핸들(8px), 치수 라벨 알약 뱃지, OSNAP 자석 표식이 함께 커져 시야를 가리는 현상을 방지하도록 역배율 렌더링 알고리즘 적용 (도면 원본만 확대되고 도구는 항상 또렷하고 슬림한 크기 유지).
스케일 측정값 불일치 해결 & 기준 문서 좌표계 고정: 뷰포트 확대/축소 시 스크롤바 유무로 인해 baseW와 캔버스 해상도가 요동치던 현상을 방지하기 위해 pdfDocBaseWidth/pdfDocBaseHeight 불변 기준 좌표계를 확립하고, 스케일 적용 시 도면 내 모든 CAD 객체의 축척(mmPerPx)을 즉각 동기화 갱신하여 2000mm 등 실제 도면 치수와 측정 결과가 100% 정확하게 일치하도록 보정.

복수 이미지 순서별 이어붙이기 (합성): 선택된 이미지들을 순서대로 세로 연결, 가로 연결, 2열 바둑판식으로 병합하여 하나의 고해상도 대형 이미지 캔버스로 작성.
선택 이미지 PDF 다중 페이지 내보내기: 선택한 이미지를 순서대로 꽉차기(Fill), 원본 비율 유지(Aspect Fit), A4 세로/가로 규격 옵션으로 고해상도 다중 페이지 PDF 생성.
PDF 100% 반응형 전체 작업창 & 우측 잘림 제거: 고정 픽셀 제한을 해제하고 창 크기 및 사이드바 변화에 실시간 반응하여 우측 잘림 없이 100% 꽉 찬 작업창 제공 ([ 꽉차게 (100%) ], [ 가로 맞춤 ], [ 페이지 맞춤 ], [ 줌 슬라이더 ]).
전 모듈 AI 지능형 협업 스튜디오 (Universal AI Collaboration Suite):
워드, 엑셀, 한글, PDF, PPT, 텍스트 등 모든 모듈에서 1) 페이지별 번역, 2) 핵심 요약, 3) 심층 해설 및 설명, 4) 전체 페이지 및 내용 구조 구분을 1클릭 수행.
사용자의 추가 지시사항을 최우선으로 반영하며, AI 공급자(Gemini, agy, OpenAI, Claude, Ollama) 및 모델/API 키를 언제든 실시간 재검토하고 자유롭게 변경 가능.
PDF 전자결재 및 상대방 공식 승인 절차 (Approval Workflow): 담당/검토/승인 표준 결재란, 전자 인장(도장 직인), 승인 상태 배지([승인완료], [검토대기], [상신])를 도면에 배치하고 고해상도 결재 완료 PDF로 출력하여 상대방의 승인을 득할 수 있는 공식 결재 시스템 완비.
