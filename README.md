## 💡 "아직도 비싼 소프트웨어를 따로따로 결제하고 계신가요?"

건축·인테리어 도면을 열어 치수를 재려고 비싼 **CAD 프로그램**을 사고,  
견적서 작성을 위해 **엑셀**을 켜고, 시방서 확인을 위해 **한글(HWP)**을 실행하고,  
발표 자료를 만들기 위해 **파워포인트**를 오가며 창을 수십 개 띄우던 번거로움—

> **이제 단 하나의 앱, `OFFICE BIN`으로 모든 업무를 단번에 끝내십시오!**

**`OFFICE BIN`**은 현장 실무자, 건축·설비 엔지니어, 공무 담당자, 학생, 전문 기획자를 위한 **차세대 통합 스마트 오피스 & 전문 PDF 도면 물량산출(Takeoff) 스튜디오**입니다.

## 🔥 OFFICE BIN 3대 핵심 혁신 기능

### 1. 📐 혁신적인 PDF 도면 실측 & 물량산출 (Takeoff) 스튜디오
더 이상 무거운 캐드 프로그램을 띄울 필요가 없습니다. PDF 도면을 열고 클릭 몇 번이면 정확한 실측과 물량 산출이 끝납니다!

- **2점 터치 스케일 맞춤 (Calibration)**: 도면 상의 기준 치수 2점을 클릭하여 픽셀을 실제 치수(mm/m)로 1초 만에 캘리브레이션. 마우스 휠 최대 **500% 초정밀 줌인** 지원.
- **PL 연속선 실측**: 배관, 전선, 벽체 길이를 연속 클릭하여 측정하면 각 변의 치수와 함께 총 누적 산출식($L: 1.20 + 2.40 = 3.60\text{ m}$)이 실시간 자동 표기.
- **건축 사선 틱 & 화살표 치수선**: 건축 도면 표준 45° 사선 틱(Tick) 및 화살표 스타일 지원.
- **면적 & 체적($m^3$) 자동 적산**: 사각, 원형, 다각형 면적을 드래그 한 번으로 실측하고, 층고(높이) 입력 시 콘크리트 타설 부피($m^3$) 동시 계산.
- **독립 해치(Hatch) 패턴 엔진**: 45° 사선(ANSI31), 교차 격자, 점박이(콘크리트), 벽돌(조적) 패턴을 지정한 폐곡선 영역 내부에만 100% 정밀 클리핑 마스크 렌더링.
- **수량 카운팅 마커**: 조명, 콘센트, 밸브 등 도면 기호를 클릭할 때마다 1, 2, 3... 번호가 자동 증가하는 마커 배치.
- **📊 엑셀 시트 1클릭 자동 연동**: 도면에서 산출된 모든 길이, 면적, 체적, 수량이 내장 스프레드시트 내역서로 즉시 자동 전송!

---

### 2. 📑 워드 · 엑셀 · PPT · 한글(HWP) 완전 통합 오피스
MS Office나 한글 프로그램이 PC에 설치되어 있지 않아도 완벽하게 문서를 열고 편집할 수 있습니다!

- 📄 **워드 (Word Docs)**: WYSIWYG 리치 텍스트 에디터, 정밀 mm 눈금자, 표준 DOCX 직접 열기 및 생성.
- 📊 **엑셀 (Excel Sheets)**: 초고속 대용량 스프레드시트 엔진, `=SUM()`, `=AVERAGE()`, `=IF()` 등 주요 수식 지원, 도면 물량산출서 자동 연계.
- 📽️ **파워포인트 (PPT Slides)**: 16:9 슬라이드 제작, F5 풀스크린 프레젠테이션, **AI PPT Master** 자동 슬라이드 생성 파이프라인.
- 🇰🇷 **한글 (HWP / HWPX)**: Rust WebAssembly 기반 초고속 렌더러 탑재. 복잡한 표, 글자 서식 등 원본 레이아웃 1:1 완벽 보존.
- 📝 **마크다운 & 마인드맵 & HTML**: 실시간 프리뷰 마크다운 편집기, SVG 베지어 곡선 아이디어 트리, 실시간 웹 에디터 내장.

### 3. 📱 아이패드(iPad) 완전 단독 실행 (True Standalone)
PC 서버가 켜져 있어야만 접속할 수 있는 반쪽짜리 웹앱이 아닙니다!

- **단 하나의 단독 파일 (`OFFICE_BIN_iPad_Standalone.html`)**:
  - 에어드롭(AirDrop)이나 카카오톡으로 아이패드로 보낸 뒤 터치하기만 하면 끝!
  - **PC 서버 ZERO! 와이파이 ZERO! 인터넷 연결 ZERO!**
  - 공사 현장, 비행기 안, 야외 어디서나 애플 펜슬로 도면을 열어 칫수를 재고 물량을 산출할 수 있습니다.
- **PWA 홈 화면 등록 지원**: 사파리 [공유] ➔ '홈 화면에 추가'를 누르면 아이패드 바탕화면에 고화질 정식 앱으로 영구 설치됩니다.

## 🚀 빠른 시작 가이드 (Quick Start)

### 1) Windows
1. [`OFFICE_BIN_Setup.exe`](https://github.com/Gimsphil/OFFCEBIN-1/raw/main/OFFICE_BIN_Setup.exe)를 다운로드하여 더블 클릭하면 자동으로 설치됩니다.
2. 무설치로 사용하시려면 [`OFFICE_BIN_Windows_Portable.zip`](https://github.com/Gimsphil/OFFCEBIN-1/raw/main/OFFICE_BIN_Windows_Portable.zip)의 압축을 풀고 **`run.bat`**을 실행하세요.

### 2) iPad (아이패드)
1. [`OFFICE_BIN_iPad_Standalone.html`](https://github.com/Gimsphil/OFFCEBIN-1/raw/main/OFFICE_BIN_iPad_Standalone.html) 파일을 다운로드합니다.
2. 아이패드의 **'파일(Files)' 앱** 또는 사파리에서 해당 파일을 열면 즉시 전체 화면 네이티브 스튜디오가 실행됩니다!
